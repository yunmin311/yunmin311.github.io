# 正式网站接入说明

认可的设计现在已经装进原来的 Astro 项目。首页、作品、文章、项目想法和关于页面使用同一套蓝色细砂与玻璃样式，原网址保持不变。

## 在本地看

运行 `npm install`，随后 `npm run dev`。正式页面是 `/zh/` 和 `/en/`，不再需要打开几十 MB 的单文件设计稿。提交前运行 `npm run check` 和 `npm run build`。要检查真正上线时的文件，构建后运行 `npm run preview`。

## 之后往哪里加内容

| 要加的东西 | 位置 |
| --- | --- |
| 作品、封面和视频链接 | `src/content/works/zh`，英文对应放 `en` |
| 文章 | `src/content/posts/zh`，英文对应放 `en` |
| 六个旧项目的后续说明 | `src/content/projectIdeas/zh` |
| 个人简介 | `src/pages/[lang]/about.astro` |
| 项目记录、学习、代码条目 | 从原来的 Obsidian 同步；不要手写三个机器管理目录 |
| 播放器真正使用的音乐 | 当前仍为交互声音试样，选定内容后再替换 |

旧项目的文章正文已原样保留；项目状态只是 2026 年 5 月旧稿里的状态，不是对目前进度的判断。其他还没有真实内容的展示继续标记试样或待补。

字体文件带完整许可证，新内容加入未覆盖的中文字后运行 `npm run paper:fonts`；这一步需要联网，日常构建不需要。所有正式源码都在本仓库，换电脑不用带旧的 personal-website 项目，也不需要任何 AI 账号密钥。

## 验收与上线

逐项检查记录在 `docs/verification`。用户已确认本版为设计基准，并授权本轮提交、推送至原 GitHub 仓库。设计基准见 `docs/design-baseline-2026-10-03.md`。用户随后明确要求直接公开上线，GitHub Pages 现由 main 推送自动构建发布，并保留手动触发。占位内容继续保留，不必等待全部填完。发布状态以 Actions 成功和线上验证为准。

模型数据已内嵌到 `model.json`，不再自动下载 `.bin`。音乐只在点击播放后加载 `music-study.json`，页面打开和播放器展开均不加载音频；正常播放、收起及刻度仍使用同一个音频实例。

## 性能维护（2026-10-04）

沿用原定稿，集中构图试验已撤销。普通构建会从原 PNG 生成逐像素一致的无损 WebP，并压缩脚本及样式；保留原 PNG 作为兼容备用。控件不再等待模型、完整许可文本和云层全部下载；云层首层先显示、其余两层继续预取。下方砂画组件接近屏幕时加载，不删内容或材质。使用完整缓存照片和模型贴图时不再重复解码原 atlas。

首页中英文切换在同一页面更新，保留模型、音乐和滚动，同时更新 URL；直接打开两个语言网址仍可用。图形能力不足时有平面卡片和 Canvas 备用路径。真实手机和不同浏览器仍需补测，模拟结果不能代替真机。测试记录与固定条件测速见 `docs/verification/performance-experiment-2026-10-04.md`。

## 内容放在哪里

- 作品：`src/content/works/zh/` 与 `en/`；封面放 `_covers/`，正文图片放 `_images/`。写作模板已在 README 第二节。
- 文章：`src/content/posts/zh/` 与 `en/`；模板见 README 第三节。未准备公开的条目用 `draft: true`。
- 历史项目想法：`src/content/projectIdeas/zh/`。旧稿保留原始日期和历史状态；确认当前进展后再更新，英文配套接入时单独验收。
- 关于：`src/pages/[lang]/about.astro`，旧稿来源为 `src/data/legacy-profile.json`。
- 项目记录、学习和代码同步区：`src/content/reflections`、`learning`、`code` 由 Obsidian 管线管理；回笔记来源修改后同步，不直接手写这些目录。
- 影集、音乐和部分素材目前由首页组件、互动源码和资产承载，还不是通用内容集合。拿到真实材料后逐项接入，不直接覆盖整份图片合图或模型缓存。

## 每一批内容的检查

1. 检查标题、简介、日期和个人角色是否真实；样例、历史内容、缺项是否仍能辨认。
2. 检查中英文列表、详情、翻译切换、图片说明与外链。首页文章和作品由内容集合读取；其他区域需检查是否仍在展示试样。
3. 图片按 `docs/图片入库工序.md` 处理，保留现有云层素材和性能策略。新增字体字形时运行 `npm run paper:fonts` 并核对许可。
4. 运行 `npm run check`、`npm run build`，在宽屏与窄屏检查文字溢出、图片比例和打开/返回交互。
5. 推送经过确认的具体文件后，等待 Pages 发布成功，再检查线上中文、英文及本批实际内容。

本清单是填充准备，不代表以上内容已提供或已填完。

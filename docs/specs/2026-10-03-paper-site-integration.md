用户在本对话明确认可「细砂与柔光层级」之后的方向，并于 2026-10-03 授权本对话转为网站实现，沿用仓库和 https://yunmin311.github.io。此记录补充 7 月规格的视觉与交互；发布仍需用户明确指令。

- 首页保持已认可的冷蓝、细砂云层和玻璃控件；主角字号桌面 76、平板 64、手机 54px，正文 16/15px。
- 上方主导航随首屏离开；下方章节导航继续收展、随滚动停靠。窄屏支持滚轮横移，没有可见滑条。
- 三张照片展开时保留两张的可点击边缘，点击照片直接切到对应内容。三横杠控件搬入阅读头部，键盘 Home/End 和左右键可持续切换，手机同样可用。
- 整站隐藏原生滚动条及底部直线进度条，但保留原生滚动。右侧刻度优先控制已打开的文章/弹窗，没有内部滚动时控制页面；没有可滚动范围时不显示虚假进度。表格和代码仍可横向滚动。
- 音乐使用默认收起的侧边小播放器，同一音频实例在收起、阅读、图像浏览时继续播放。当前声音为 24 秒合成试样，不是已选真实音乐。完整播客设计已存档。
- 字体、材质、模型、代码与许可都在本仓库；运行与构建不读取设计稿、旧项目或本机绝对路径。字体从服务商获取本站字表版本，无本地裁剪或改名；完整许可在 public/assets/paper/LICENSES。

## 正式源码的入口

首页 `src/pages/[lang]/index.astro`；分区 `src/components/paper`；样式 `src/styles/paper`；互动 `src/scripts/paper`；共享详情布局 `src/layouts/Base.astro`；内容查询 `src/lib/paper-home.ts`。

`npm run dev` 与 `npm run build` 会先生成本地互动资产。日常更新正文只编辑内容文件；加入新中文字后，可运行 `npm run paper:fonts` 更新服务商字表。普通构建无需联网下载字体。旧设计对比保存在 `design/纸窗-卡片切换与统一刻度定稿-2026-10-03`。

用户后续已明确确认设计定稿，并授权提交与推送至原 GitHub 仓库。GitHub Pages 保持手动部署；本轮不触发部署。设计基准见 `docs/design-baseline-2026-10-03.md`。

## 下载接管兼容修复

模型缓冲内嵌到 model.json，页面不再请求 .bin。音乐试样使用普通 JSON 资源，只有首次明确播放时才解码为本地 Blob 并接到同一个播放器；打开页面和展开播放器不下载音频。此调整避免原网页的自动媒体下载请求，不修改用户本机 IDM 注册信息或浏览器扩展。

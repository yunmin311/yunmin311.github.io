## 保留与改变

- 素材、冷蓝基调、原有内容和模块保留；原图、缓存清单不覆盖。
- 九份砂画素材生成无损 WebP，逐个解码比较原图 RGBA，全部相同。构建脚本可重建实验资产。
- 首页中英文使用原位更新，保留页面、卡片、音频和滚动；对应 URL、网页语言、描述、阅读入口同步。浏览器后退、前进恢复语言，直接访问两个 URL 仍由 Astro 生成。
- 原实现把英文文章列表清空，本分支保留内容集合的英文列表，不再强制清空；目前正式英文文章仍为零，没有生成译稿。
- 3D、材质、控件分别加载。WebGL 创建失败或模型加载失败时提供三张可点击平面卡片；3D 上下文丢失时也保留阅读入口。云层失败改用 Canvas，WebP 解码失败尝试原 PNG。
- 许可全文不再阻塞控件；字体先显示后替换；照片卡片不再等待无关字体。
- 云层首先加载当前画面，后续画面继续预取；下面砂画组件接近视口时加载。
- 实验使用共同的 960 × 1440 云层采样网格；缩放与纵向位移对齐整数颗粒。手机地址栏引起的高度变化不再重算世界采样高度；实际效果仍需真机滚动录屏评判，本轮不宣称消除所有抖动。

## 验证方式与局限

`npm run build`、`npm run check`；浏览器脚本 `scripts/qa/paper-performance-experiment.cjs` 覆盖桌面、390px 手机模拟、无 WebGL、减少动效、禁用 WebP 解码的五种情况。检查无横向溢出、打开卡片、语言切换保留对象、后退恢复语言。

浏览器检查使用 Chromium 软件渲染。手机模拟不是手机真机，不能代表 Safari、各品牌内嵌浏览器或用户提及但尚未确认名称的浏览器。仍需不同引擎及真实设备补测。

限速比较使用同一台本地静态服务、空缓存、约 4.1Mbps 下载、80ms 延迟；本地服务器没有 gzip，不能用这些数字预测 GitHub Pages 的实际秒数。

## Project

A temporary workspace beside ChatGPT gives the user control over material selection and output instructions. It supports whole messages, Q&A pairs and selected excerpts, then compiles and previews a deterministic prompt.

## Status and boundaries

No model API or server. Work is transient by default; optional local snapshots and locally stored preferences are described in the privacy document. ChatGPT integration depends on the host interface.

## Project

The standard distinguishes Chat Mode and Document Mode, semantic hierarchy and rendering constraints. Rule data, good/bad examples and a Python validator make the supported checks reproducible.

## Status and boundaries

Static checks do not evaluate the complete semantics of a document. The validator is not a full Markdown AST; human review remains necessary.

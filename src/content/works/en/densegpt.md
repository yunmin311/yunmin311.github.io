## Project

One UserCSS file controls the reading layout and content width; STYLE.md and presets guide the density of the answer itself. Either layer can be used on its own.

## Status and boundaries

The layout layer uses Stylus. It does not inject JavaScript or make network requests. Response instructions guide writing, rather than guaranteeing model behavior.

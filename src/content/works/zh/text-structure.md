## 项目

规范区分 Chat Mode 与 Document Mode、语义层级与渲染约束。规则数据、正反例和 Python 验证器让支持范围内的检查可以复现。

## 状态与边界

静态检查不能评价整篇文档的语义。验证器不是完整 Markdown AST，仍需人工复核。

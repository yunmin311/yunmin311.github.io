## 什么是 Vibe Coding

Vibe Coding 是借助 AI（Claude、Cursor 等）进行编程的方式——不是替代你思考，而是让你专注于「做什么」而非「怎么写」。就像和一位高级工程师结对编程。

## Heatmap 项目

第一个 Vibe Coding 项目选择了一个时间热力图，可以：
- 从 GitHub API 拉取 commit 数据
- 用 D3.js 渲染热力图
- 展示多个项目的活跃时间段

## 收获

1. **先想清楚再写** — AI 能帮你写代码，但前提是你知道要什么
2. **迭代式开发** — 从 MVP 开始，逐步添加功能
3. **验证很重要** — 每一轮的产物都要验证是否符合预期

## 经验总结

Vibe Coding 的核心不是「偷懒」，而是「加速」。把重复性工作交给 AI，把判断力留给自己。
